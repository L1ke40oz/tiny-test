## 历史与迁移记录

- 七个项目的默认分支文件按原路径、文件内容和 Git 对象完整导入同名子目录。
- 未压缩原提交历史；原 main 提交是导入合并提交的父提交，保留原作者、日期与 SHA。
- 原分支保存在 `archive/原仓库名/分支名`，这些归档分支保持原仓库根目录布局，便于恢复。
- 迁移清单和原仓库公开元数据见 [`_migration/`](./_migration/)。各项目的许可证保留在原文件夹中。
- 原仓库 GitHub Pages 地址不会自动重定向到子目录；页面部署信息已归档，本仓库未自动开启 Pages。
- 本次迁移只整理项目，不统一依赖、不改写项目源码，也不运行原仓库的安装脚本。
