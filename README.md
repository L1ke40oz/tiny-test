# 沙画 (Sand Painting)

陀螺仪驱动的落沙模拟 —— 一个沙画填色小游戏的技术验证。

## 在线试玩

**https://l1ke40oz.github.io/sand-painting/**

用手机或平板打开。点「开启陀螺仪」，iOS 会弹一次系统授权框，选「允许」。

## 这个页面在验证什么

1. **浏览器能不能拿到陀螺仪数据** —— iOS 需要 HTTPS + 用户手势触发授权，这也是必须部署到 GitHub Pages 而不能用本地文件的原因
2. **落沙模拟的手感和性能** —— 元胞自动机，重力方向由设备姿态决定

## 界面说明

顶部 HUD 实时显示：

| 字段 | 含义 |
|---|---|
| 传感器 | 已授权 / 被拒绝 / 无传感器 / 手动模式 |
| 事件 | 收到的 `devicemotion` 事件数。**一直是 0 说明设备没有传感器或没授权成功** |
| secure | 绿色 = HTTPS。红色则 iOS 一定会拒绝授权 |
| 原始 | 传感器原始读数 x/y/z |
| 重力 | 换算到画布坐标系后的重力方向 |

底部工具栏：

- **调色板** —— 选颜色，在画布上按住拖动即可倒沙
- **橡皮** —— 擦掉沙子
- **清空** —— 清空画布
- **反转 X / 反转 Y** —— 如果沙子流向和设备倾斜方向相反，用这两个按钮校正

如果设备没有陀螺仪，右下角会出现一个手动重力盘，拖动小圆点即可改变重力方向。

## 性能

在 iPad 满屏规模（256×192 = 49152 格，45% 填充）下实测模拟耗时 **0.6 ms/帧**，每帧预算 16 ms。纯 JavaScript 足够，无需 WebGL。

## 技术要点

- `devicemotion` 的 `accelerationIncludingGravity` 直接给出重力方向，比 `deviceorientation` 的欧拉角好用（无万向锁问题）
- 沙子网格存在 `Uint8Array` 里，逐格更新
- 遍历顺序必须从「重力下游」往「上游」走，否则同一粒沙会在一帧内被反复推进
- 渲染走网格分辨率的离屏 canvas，再用 `imageSmoothingEnabled = false` 放大，保留颗粒感

## 已知限制（iOS Safari 网页版）

| 能力 | 支持情况 |
|---|---|
| 陀螺仪 | ✅ 需 HTTPS + 用户手势授权 |
| 震动反馈 | ❌ 不支持 `navigator.vibrate` |
| 锁定竖屏 | ❌ 不支持 Screen Orientation Lock |
| 全屏 | ❌ iPhone 上无 Fullscreen API |

如果后续需要这些能力，可以用 Capacitor 套壳，同一份代码即可拿到原生传感器、触感反馈和屏幕方向锁定。
