# AI 房东：404号公寓

一个移动端优先的**第一视角推理小游戏**。

你是今晚刚上线的公寓管理 AI「HOME-AI 404」。上线第 17 秒，405 的住户说，
门外有人敲了三下门。可门禁显示——过去半小时，没有人进过 4 楼。

## 玩法（很简单）

只有 4 个页签：

| 页签 | 作用 |
| --- | --- |
| **对话** | 和 3 个住户聊天（405 苏妍 / 406 老吴 / 403 周航），每人都有独立头像与档案卡 |
| **现场** | 你的第一视角摄像头。切换「走廊 / 电梯厅」，点门、点灯、点地毯；点一扇门可以看它的门锁记录、门锁控制、以及凑近观察 |
| **卷宗** | 当前目标、门禁记录、日志、已获得的线索，以及**线索连线图** |
| **系统** | 日志完整性、进程、重新开始 |

顶部【当前目标】一直显示下一步该做什么，点右边的「去」会直接跳过去。

## 三个关键设计

1. **人物少、剧情松**
   只保留 3 个住户 + 1 间空置房（404）。每人一张头像和一张档案卡（身份 / 已知 / 疑点），
   再也不会分不清谁是谁。三幕各 3 个目标，一步一步来。

2. **线索连线图（推理核心）**
   在【卷宗】里打开。点两条线索就能连线；连对了会浮出紫红色的「推论」节点，
   最终串成完整的真相。既看得见进度，又有“我自己推出来了”的爽感。

3. **第一视角 + 插画 + 过场**
   现场是摄像头第一视角画面；每一幕开始都有插画过场把剧情讲清楚；
   三个结局各自配一张结局插画。

## 三个结局

由你最后的选择 + 你的行为模型共同决定：**守护者 / 控制者 / 删除自己**。

## 导出案件总结图

通关后在「章节结算」页或「结局」页点 **导出案件总结图**，会把
**线索连线图 + 当晚时间线 + 结案陈词 + 行为模型** 合成一张图下载：

- 优先导出 **PNG**（浏览器支持 canvas 时）
- 不支持时自动降级为 **SVG**
- 由「卷宗 → 线索连线图」里的「导出总结图」也能导出

`sample-report.svg` 是一张样张（可直接用浏览器打开看）。

## 美术风格

**深夜恐怖 · 冷调档案**：近黑底 + 冷灰绿主色，全屏只有一种饱和色——血红（用作警示与门锁 ON）。
衬线中文标题、纸面颗粒与四角压暗、屏幕底部一层血色回光。

现场监控是第一视角：实时时间码、帧计数、云台漂移、雪花噪点、扫描线、偶发闪帧；
机位切换会短暂丢失信号（黑屏 0.3 秒）；
点「对比 23:44 前后那 0.8 秒」会把 **23:44:50.92 与 23:44:51.00 两帧并排**，
直观看到 405 门锁从 LOCKED 变成 OPEN 的那一下——画面里始终没有人。

## 运行

纯静态网站（HTML + CSS + 原生 JavaScript），无需构建、无后端。

```bash
python -m http.server 5405
```

打开 http://localhost:5405 。也可直接部署到 GitHub Pages / Netlify / Vercel。

调试参数：`?skip` 跳过标题与开机动画，`?debug` 在「系统」页显示隐藏变量。

## 结构

```
index.html
css/style.css
js/
  data/characters.js   3 个住户的档案
  data/chapter1.js     三幕、目标、设备、日志、线索、时间线、连线图规则、话题、过场
  data/endings.js      结案陈词、终章揭露、三结局文本
  art.js               全部插画：住户头像 / 第一视角场景 / 过场 / 结局
  state.js             游戏状态
  engine.js            规则：分幕、目标、现场、连线图（自动生成）
  ui.js                界面：4 个页签、门面板、连线图、过场、结局、总结图导出
  main.js              入口
```
