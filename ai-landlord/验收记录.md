# 第一章 Demo 验收

日期：2026-10-24。验证环境：Windows / Chromium / Playwright CLI。当前为场景探索版，替代最初仅以控制台为主的原型。

## 已通过

- 开局进入四楼走廊；与 405 通话后可进入室内示意。
- 无保险丝不能修复照明；黑暗中不能提前发现维修卡。
- 打开维修箱与拾取保险丝是两个实际操作，场景中物体状态会改变。
- 选中保险丝并点击配电箱后安装成功，道具消耗、回路修复。
- 开灯后场景改变光照，苏妍发来消息；翻地垫后维修卡才显现。
- 维修卡打开检修面板，取出记录芯片；芯片接入终端才允许关联扫描。
- 室内猫眼、门锁、手机、手册、窗户可调查；旧版住户守则进入道具栏。
- 在场景中联系 405、询问 406 可取得主线证据。
- 封存未知访问后刷新页面，删除剧情仍会继续；只读证据摘要保留。
- 同一份调查进度可分别到达守护者、控制者、删除自己三个结局。
- 关机结局会释放门锁、保留照明、导出档案。
- 320 / 390 / 768 / 1440 像素宽度下，现场、住户、事件、设备、日志、监控、系统均没有页面横向溢出。
- 完整场景通关脚本中没有浏览器脚本异常；最终语法检查通过，浏览器控制台无错误。

脚本：`output/playwright/check-scene.js`。场景主线与布局合计 50 项断言通过。

截图：`output/playwright/scene-final-mobile.png`、`scene-final-desktop.png`、`scene-lit-mobile.png`、`room405-mobile.png`。

## 验证范围

浏览器自动化通过本地 HTTP 服务器运行。代码不依赖模块加载、外部请求或网络资源，支持直接打开 HTML；自动化工具本身禁止 file:// 导航，因此该入口未通过自动化直接验证。

响应式检查使用浏览器模拟视口，尚未进行实体手机 Safari、低版本浏览器或触摸硬件测试。当前只有第一章；第二章与真实手机传感器尚未实现。
