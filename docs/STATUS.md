# 本地试玩版进度

更新：2026-10-22（America/Los_Angeles）。本文件描述当前实现；DEVELOPMENT.md 描述完整目标。

## 当前交付

已完成供本机多窗口试玩的 v0.1。房间数据在内存中，服务重启后清空；游客身份按标签页保存，刷新可恢复，复制标签页可能转移原身份控制权。

- 原创森林史莱姆、像素角色、桌面双栏与移动端两列答题界面。
- 史莱姆加入轻微上下浮动与呼吸式伸缩，待机和受击分层；遵循界面及系统的减少动画设置。

- 建房、邀请二维码/链接、房间码加入，最多 6 名参战、房间总人数上限 8。
- 20 道服务端题库，每局随机不重复抽取 15 道，限时 8 / 10 / 15 秒。
- 全员提交提前结算，答题期间隐藏正确答案与他人选项。
- 扣血、个人伤害、连击、全员合击、零血量淘汰、胜负与再来一局。淘汰后本局只能旁观，存活者继续答题；全队倒下失败，下局恢复满血。
- 排行榜展示伤害、正确率和答对/应答题数，手机可展开查看。
- 房主参与/观战切换在下一题生效，支持暂停/继续。
- 房主动态面板显示连接、提交、角色和游戏操作，并保留已结算题目的队员选项、结果和伤害。
- 刷新/短时断线恢复、完整状态快照、重复提交防护、同身份单控制端、房间隔离。
- 主动离开房间、减少动画设置、键盘焦点、明确正确/错误文字反馈。
- Windows 双击 `开始试玩.cmd` 构建并运行；也可以通过 npm 开发。

## 当前验证

- TypeScript 类型检查和 Vite 构建通过。
- 待机动画已单独通过构建与 Chrome 检查：连续采样确认实际上下移动；界面“减少动画”与系统减少动态效果设置都能关闭它。此项改动未触及战斗规则。
- 20 项针对性测试通过：计时、权限、重复提交、旧题重放、连击、淘汰后禁答和统计冻结、重连/角色切换不能复活、全队淘汰、下局回血、胜负、历史保密等。
- 真实 Socket.IO 集成测试：6 个参战客户端、观众、重连、同身份控制权替换、房间隔离和离房。
- Playwright Chrome 实测：桌面建房、手机尺寸加入、同步结算扣血、刷新恢复、暂停、移动端布局。

- 已实际通过 Windows 启动脚本完成构建与启动，首页和健康端点均返回 HTTP 200；启动脚本使用 CRLF 行尾。

## 与完整开发文档的差异

- 原型为总人数最多 8、其中参战最多 6；目前不额外强制独立的“最多 2 名观战者”配额。
- 离线席位目前保留到房间回收，不是 60 秒；全部成员离线且无活动 2 小时后回收。
- 每题直接按服务端截止和全员提交判定结算，未实现额外结算调度宽限。
- 目前在线与离线参战者都在本题义务名单内，掉线不阻止在线者提前结束，未提交计超时。
- 成绩和历史均为内存，不跨服务器进程重启恢复。
