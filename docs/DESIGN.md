# 森林营地视觉方案

本地原型 v0.1，2026-10-22。

## 视觉约定

- 夜幕 `#171e2b`：页面与森林天空。
- 林间阴影 `#233731`：战场与植被。
- 苔绿 `#b7d58a`：队伍就绪、正确答案与主要动作。
- 旧纸 `#f1ead3`：正文与月亮。
- 雾蓝 `#97adb6`：次要文字、辅助信息。
- 陶红 `#e59b8b`：错误、受伤与紧急倒计时。

中文使用本机 Microsoft YaHei / PingFang SC / 无衬线字体，保证题目清晰。房间码与数字使用等宽字体。像素感来自原创 SVG 史莱姆、CSS 人物、切角边框和离散阴影，不给中文正文套用低分辨率像素字体。

首页让史莱姆成为记忆点，表单保持安静、明确。战斗页以题目和四个大按钮为主要操作区，地图景物不抢答题注意力。文字左对齐，角色与结算场景居中。

```text
桌面：首页                 桌面：游戏
品牌               连接     房间标题             房间码
标题 / 史莱姆     登记表单    森林战场             贡献榜
玩法提示                    答题区               房主操作

手机：品牌 → 精简介绍 → 表单
手机游戏：紧凑战场 → 答题 → 房主操作 → 可展开贡献榜
```

## 自查与取舍

夜色配绿色来自森林 Boss 主题，不扩展成通用后台卡片。按用户反馈，史莱姆加入 2.6 秒循环的轻微上下浮动与呼吸伸缩；待机与受击分层，受击的横向震动不会覆盖待机节奏。其余动效用于实际攻击和结算；不加载外部字体，减少大陆网络依赖。重点放在原创史莱姆与多人角色上，边框、章节标记和卡片层级为操作服务。

所有交互保留键盘焦点，选项同时有文字和颜色反馈，触控目标至少 44px；窄屏不横向溢出。尊重系统减少动画设置，并提供界面开关。
