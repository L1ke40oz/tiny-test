# 沙画 (Sand Painting)

陀螺仪驱动的落沙模拟 —— 一个沙画填色小游戏的技术验证。

## 在线试玩

**https://l1ke40oz.github.io/sand-painting/**

用手机或平板打开。点「开启陀螺仪」，iOS 会弹一次系统授权框，选「允许」。

## 这个页面在验证什么

1. **浏览器能不能拿到陀螺仪数据** —— iOS 需要 HTTPS + 用户手势触发授权，这也是必须部署到 GitHub Pages 而不能用本地文件的原因
2. **落沙模拟的手感和性能** —— 活动沙粒 + 静止位图的混合模型，重力方向由设备姿态连续决定

## 界面说明

顶部 HUD 实时显示：

| 字段 | 含义 |
|---|---|
| 传感器 | 已授权 / 被拒绝 / 无传感器 / 手动模式 |
| 事件 | 收到的 `devicemotion` 事件数。**一直是 0 说明设备没有传感器或没授权成功** |
| secure | 绿色 = HTTPS。红色则 iOS 一定会拒绝授权 |
| 原始 | 传感器原始读数 x/y/z |
| 重力 | 换算到画布坐标系后的重力方向 |

底部工具栏：

- **调色板** —— 选颜色，在画布上按住拖动即可倒沙
- **橡皮** —— 擦掉沙子
- **清空** —— 清空画布
- **反转 X / 反转 Y** —— 如果沙子流向和设备倾斜方向相反，用这两个按钮校正

如果设备没有陀螺仪，右下角会出现一个手动重力盘，拖动小圆点即可改变重力方向。

## 性能

活动沙粒上限 2 万，静止沙烘进位图。倒一大堆沙（约 2900 粒）落定后，实测模拟 **0.7 ms/帧**；沙堆静置时 relax 每帧全扫一遍位图，也只要 **0.85 ms/帧**。每帧预算 16 ms，纯 JavaScript 足够，无需 WebGL。

## 技术要点

模型分两半：**空中的沙是浮点粒子**（`pX/pY/pVX/pVY`，子步积分、亚像素移动），**落定的沙烘进 `Uint8Array` 位图**。

- **连续重力**：粒子加速度直接用 `gx*ACCEL / gy*ACCEL`，方向不量化，倾斜时沙堆连续偏向低处
- **占用表 `occ`**：一格只准站一颗活动粒子，否则一股沙流会把几千颗塞进同一格
- **计数排序**：按重力方向从下游往上游算，一整柱停住的沙能在同一帧从下往上整根沉下去
- **休止角交给 `relax()`**：在位图上做「格到格」的搬运——悬空的沿重力落到底，坡太陡（落差超过 `tan(33°)`）的横移一格再落。休止角实测 ~32°。不在粒子阶段管休止角：斜向重力下那样会让整坡沙卡成永不落地的活粒子
- **每粒独立配色**：每种颜色预生成 16 组 HSL 微扰的 RGBA，按 `seed & 15` 查表，零每帧开销又不会「闪」
- 渲染走网格分辨率的离屏 canvas，再用 `imageSmoothingEnabled = false` 放大，保留颗粒感
- 重力来自 `devicemotion` 的 `accelerationIncludingGravity`，比 `deviceorientation` 的欧拉角好用（无万向锁问题）

## 已知限制（iOS Safari 网页版）

| 能力 | 支持情况 |
|---|---|
| 陀螺仪 | ✅ 需 HTTPS + 用户手势授权 |
| 震动反馈 | ❌ 不支持 `navigator.vibrate` |
| 锁定竖屏 | ❌ 不支持 Screen Orientation Lock |
| 全屏 | ❌ iPhone 上无 Fullscreen API |

如果后续需要这些能力，可以用 Capacitor 套壳，同一份代码即可拿到原生传感器、触感反馈和屏幕方向锁定。
